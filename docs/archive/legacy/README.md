# Historical pilot — uncorrected research record

These files preserve the initial repository, including saved outputs and the original figure. They contain interpretations the current study does **not** treat as established: monosemantic self-monitoring, orthogonal circuits and proof of illusionism.

Original scripts are provenance, not the supported execution path. They contain automatic fallback and partially unpinned installation instructions. Use the shared CLI instead.

The examples used ten contrast prompts, one generation prompt and seed 42. The plot is an unembedding projection, not a measure of metacognitive performance or consciousness. No GPU rerun was performed when this archive was created.
